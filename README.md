# GymTrack — Android MVP

Первая версия дневника тренировок.

## Уже работает
- Главный экран и статистика
- Создание тренировки
- Добавление подходов: упражнение / вес / повторы
- Сохранение данных между запусками через SharedPreferences
- Отдельное отображение последней тренировки
- Учёт лучшего значения для упражнений с названием, содержащим «жим»
- Заготовка под GymTrack Pro

## Как собрать
1. Открой папку `GymTrack` в Android Studio.
2. Дай Gradle скачать Android Gradle Plugin и зависимости.
3. Нажми Run для запуска на телефоне/эмуляторе.
4. Для APK: Build → Build APK(s).
